# Beginner Questions

🟢 Beginner (Challenges 3.1 – 3.10)
Challenge 3.1: Write a script greet.sh that takes a name passed as $1 and prints "Hello, <$1>! Welcome aboard.".

Challenge 3.2: Create a script duo.sh that captures $1 (First Name) and $2 (Last Name) and prints "Full Name: $1 $2".

Challenge 3.3: Write a script party.sh that takes an arbitrary number of guest names passed as arguments and prints "Total guests: $#" and "Guest list: $@".

Challenge 3.4: Write a script that takes a number variable level=1 and increments it by 1 using (( level++ )).

Challenge 3.5: Create a multiplier script that takes a single number as $1 and calculates its double using (( result = $1 * 2 )).

Challenge 3.6: Create a score splitter that takes a total score passed as $1 and calculates a quarter share using (( share = $1 / 4 )).

Challenge 3.7: Generate a random integer between 0 and 4 using modulo arithmetic (( roll = RANDOM % 5 )).

Challenge 3.8: Check if a target file path passed as $1 exists and is a regular file using [ -f "$1" ].

Challenge 3.9: Calculate the modulus (remainder) of dividing $1 by 2 using (( remainder = $1 % 2 )) to test if a number is even or odd.

Challenge 3.10: Calculate the square of an input integer $1 using exponentiation syntax (( square = $1 ** 2 )).
